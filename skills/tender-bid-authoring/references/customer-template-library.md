# 客户独立模板与完整章节模块库

## 核心边界

客户模板是按真实客户实体、历史项目和来源哈希建立的独立资产，不是把同一份通用DOCX复制后更名。每个客户包分别管理价格、商务、技术模块；三个领域可以来自该客户不同历史项目。客户包缺少某个领域时标记`missing_customer_specific_source`，不得用其他客户模板静默补齐。

客户模板库负责客户专属章节选择和成熟版式，[模块化权威库](authority-module-library.md)负责可追溯的章节、表格、响应和证明材料模块。两者均不能决定本项目事实：客户模板命中后仍须用模块ID记录实际采用内容，模块命中后仍须服从客户模板、招标结构和当前证据。

客户名称先经规范表解析：客户实体、集团、矿井/项目公司、历史简称和项目名称分别保存。项目名、车型名、文件标题误入客户字段时，只有存在现行权威库证据或明确别名映射才归并；不能确定法定全称时使用暂定客户名并标记`provisional`，不得推造公司全称。

## 资产契约

客户模板库目录由`BID_CUSTOMER_TEMPLATE_DIR`或`--template-dir`明确指定，至少包含：

- `customer.templates.meta.json`：版本、上游权威库版本、客户数和模板哈希；
- `customer.templates.json.gz`：客户、案例、来源文件和完整章节模块；
- `customer_templates/<customer-id>_<name>/manifest.json`；
- 每个客户的`price_modules.json`、`business_modules.json`、`technical_modules.json`；
- `scoring_directory_candidates.json`：可由评分项选择的成熟章节候选。

每个模块至少记录客户、领域、完整标题和正文、来源项目、来源文件及哈希、车型、年份、替换字段、正文指纹和复用策略。正文指纹出现在多个客户包时标记`shared_historical_text_requires_customer_specific_adaptation`，不能作为任一客户的默认专属模板。

## 选择与降级

1. 精确匹配当前客户实体；
2. 匹配该客户已登记别名；
3. 同集团且同采购/维修/租赁业务，只作为显式降级候选；
4. 同业务类型或同车型其他客户，只作为普通参考；
5. 没有客户专属来源时新写，或经业务确认采用降级候选。

不得因为同集团、同车型或正文相似就跳过客户匹配。任何三级、四级降级均在复用台账记录来源客户、降级原因、当前项目修改字段和核验结果；正式正文不得残留来源客户名称、项目编号、地点、人员、日期、数量、期限或附件页码。

## 完整章节复用

模块化制作以完整章节、完整表格或连续措施组为最小复用单位。召回时保留标题、全部子标题、正文、表格、流程、措施和附件引用，不把成熟内容压缩成几句模型概述。采用方式：

- `Exact Reuse`：客户、要求、配置和义务相同，仅替换本项目固定字段；
- `Adapted Reuse`：以完整模块为基线，针对本项目差异作最小增删；
- `Fresh Generate`：客户库没有适用完整模块时才新写。

价格模块只允许复用结构、列项、公式和版式。历史金额、税率、折扣、单价、总价、保证金金额及报价有效期必须从本项目真实数据重新填写。

## 满分评分目录驱动

先解析评分表，再编排正文。每个评分项建立：

`评分项 → 满分条件 → 可验证评价对象 → 招标强制父章节 → 子级目录标题 → 客户完整模块 → 本项目修改字段 → 证明材料`。

子级标题直接采用评分细则中的高分/满分特征或完整等义表达，不再只用评分项简称；保留横向对比、优于、完整齐全、具体措施和证明类型等得分特征，但不写分值和“确保满分”。商务评分节点分别落入对应的资格、业绩、业主评价、认证或其他商务章节，不在商务扉页下平铺。满分条件包含多个对象时分别设子标题；同一证明支持多个评分项时可交叉引用，不重复堆附原件。目录节点没有正文和证据时不得建立；正文没有目录归属时不得作为评分内容插入。目录确认后，内容生成只能沿目录树装配，标题、正文、表格、附件索引和最终页码使用同一节点ID。

## 项目开始检查

1. 运行`customer_template_assets_check.py`核对模板库完整性和哈希；
2. 用`customer_template_recall.py --customer`精确命中客户；
3. 分别查看价格、商务、技术模块和缺失领域；
4. 形成评分目录映射后再选择完整模块；
5. 对跨客户共享模块或降级候选执行客户字段替换检查；
6. 最终按历史反馈清单逐页核对目录、正文、附件及旧项目残留。

模板库校验成功只证明资产结构可读，不证明具体模块适用于当前项目，也不证明投标文件可正式递交。
