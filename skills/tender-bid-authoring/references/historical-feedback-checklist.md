# 历史业务反馈问题自查清单

本清单汇总已经被业务人员实际指出过的制作问题。第十步必须使用同一批最终页图同步执行视觉逐页检查和问题清单反查：先逐页判断本页适用的检查项，再按检查项反查全卷。清单用于发现可观察缺陷，不替代招标原文、企业事实和技术证据判断。本次业务决定业绩与正式商务、技术偏差表留空，下列旧反馈的实填条件须按此决定更新适用性。

## 记录方式

每条记录至少包含：`检查项编号｜适用/不适用及依据｜产物与版本｜页码或DOCX位置｜实际观察｜结论（通过/已修订/未解决）｜修订后复查页码`。

- 不适用必须写明依据，不能仅填“不适用”。
- 不得批量预填“通过”；检查结论必须落到实际单元格、段落、表格、附件或页图。
- 修订导致分页变化时，复查变化页、前后衔接页、目录和全部受影响引用。
- 项目专属参数、人员、报告号和历史页码仅写入项目记录，不固化到本清单。

## A 招标原文与强制格式保真

| 编号 | 适用条件 | 检查内容与典型问题 | 通过标准 |
|---|---|---|---|
| HF-A01 | 存在投标文件格式章或附件模板 | 是否漏读模板、用自拟结构代替招标表单 | 强制标题、顺序、字段、说明和签章位均来自本项目招标格式 |
| HF-A02 | 表格为招标强制格式 | 列数、列序、表头、合并结构、行数或备注被改动 | 与原表逐格对应；允许填写内容，不擅自重构 |
| HF-A03 | 技术响应表含“招标人要求”栏 | 左侧要求被删减、改写、润色或加入“投标时符合”等投标人表述 | 编号、星号、括号、数值、单位和提交要求与固定输入逐条一致 |
| HF-A04 | 招标保留条件式或互斥表单 | 信誉承诺等原表被删除或替换为“不适用”概述 | 全部情形、固定正文、落款和顺序完整保留 |
| HF-A05 | 原表存在填空下划线 | 填值或填`/`后下划线消失、缩短成孤立斜线 | 值或`/`位于原下划线内，线条和签章空间仍清晰 |
| HF-A06 | 招标规定正式偏差表 | 用通用四列表替代六列偏差表，或删除强制页章节定位栏 | 正式偏差表完全采用招标规定结构；详细响应表与偏差表分开 |
| HF-A07 | 招标有固定分部或表单说明 | 原说明、注释、签章提示被删或改成制作说明 | 原说明保留；内部提示不进入投递文件 |

## B 项目字段与表单实填

按[field-completion.md](field-completion.md)先建清单再制作，逐表、装配后、交付前及修订后回验。HF-B08基本情况两类资质及已确认备注仍实填；HF-B09改为本次业绩原表固定内容完整、填写区空白且无业绩证明；HF-B10最终哈希对应实填与留空检查均通过且页图无隐藏/截断。

| 编号 | 适用条件 | 检查内容与典型问题 | 通过标准 |
|---|---|---|---|
| HF-B01 | 项目、标段和采购信息已明确 | 项目名称、标段号、标段名称、货物名称或型号相互替代 | 每个字段按其语义填写，并在封面、投标函、报价和交货表中一致 |
| HF-B02 | 企业普通字段已有依据 | 企业名称、地址、法人、经营期限、职务、身份证号、联系人等漏填 | 已知字段全部落到实际表单；单个待定字段不导致整表空白 |
| HF-B03 | 招标已明确截止/开标日期或业务已确认编制日期 | 封面、投标函和普通承诺日期留空 | 普通日期实际填入并保留下划线；事件日期不冒填 |
| HF-B04 | 报价或交货清单存在多行采购内容 | 采购名称、实际型号、单位、数量混列或漏行 | 采购名称、型号、单位、数量分栏管理并由同一清单驱动 |
| HF-B05 | 授权人员尚未确定但企业信息已知 | 因代理人未定而整张授权书留空 | 企业和法人已知字段实填，只有真实未定字段保留空位 |
| HF-B06 | 正式文件不得出现制作状态 | “待确认、待核对、证明未齐、AI建议、检索未找到”等进入正文 | 正文只保留正式响应、真实差异和规定引用；内部状态移出 |
| HF-B07 | 参考文件提供普通填写值 | 复制旧项目名称、客户、联系人、日期、价格或签章 | 只采用本项目已确认值；旧项目专属字段全部替换或删除 |

## C 封面、扉页、目录与编号

| 编号 | 适用条件 | 检查内容与典型问题 | 通过标准 |
|---|---|---|---|
| HF-C01 | 完整投标文件封面 | 字号、字体、项目字段或单页结构不符合确认模板 | 主标题及字段字号正确，招标强制字段齐全，封面保持单页 |
| HF-C02 | 使用已确认封面示例 | 三区挤在上部或仅按固定段距机械排版 | 主标题、项目信息、投标人/日期与示例视觉位置一致 |
| HF-C03 | 存在价格、商务、技术等分部 | 分部标题未独立成页、未居中或同义扉页重复 | 按招标结构独立成页并居中，目录收录真实扉页 |
| HF-C04 | 生成卷内或总目录 | 目录缺项、多余自拟标题、评分解释或材料说明被升级为标题 | 仅收录招标强制节点、确认子级和正文真实标题 |
| HF-C05 | 目录存在多级子标题 | `（一）`、`（1）`、`1.`、业绩编号等层级符号丢失或混用 | 编号形态、缩进和父子层级与正文及确认示例一致 |
| HF-C06 | 已完成最终排版 | 目录仍沿用旧页码、引用页码超出成品，或不同层级页码右边缘不齐 | 页码由最终渲染回填，目录、正文和材料索引可相互定位；所有层级共享同一右对齐页码制表位和点引导线 |
| HF-C07 | 同层级存在多个标题 | 字体、字号、粗细、缩进或段距不一致 | 同层级样式一致；招标原格式例外单独保留 |
| HF-C08 | 附件或原件标题含“第×页” | 制作人员自行添加卷内页码说明，或继承无依据旧标注 | 来源原件自带标注才保留；生成页码仅进入目录和正式索引 |
| HF-C09 | 分别交付价格商务卷和技术卷 | 一份目录仅列本卷，另一份目录层级不全，或两卷目录标题不一致 | 除招标明确限定本卷目录外，两卷使用同一完整项目目录，覆盖价格、商务、技术及实际子级，并按卷别标注真实页码 |
| HF-C10 | 目录父级或评分节点发生调整 | 子级仍沿用旧编号、名称与正文不一致，或把不相符附件改名成评分材料 | 子级继承当前父级编号，目录与正文逐字一致，材料名称反映实际附入原件，不冒名替代 |

| HF-D05 | 附财务、荣誉或证书 | 只堆附件，汇总表、年度标题或索引未实填 | 除本次业务指定留空表外，表格数据、年度子标题和材料索引与原件一致 |

| HF-D11 | 附入体系认证证书 | 评分用证书被放到无关章节，或非评分证书挤入评分章节 | 用于评分的证书在对应评分材料章节；否则在其他商务资料；跨处引用准确 |

| HF-D13 | 存在响应性评审需回应条款 | 专项承诺函只写“完全响应”或遗漏评审项 | 一份响应性评审承诺函逐项覆盖全部需回应条款，并与投标函及技术响应一致 |
| HF-D07 | 旧名称主体材料被采用 | 未附更名衔接，或把更名直接等同于材料适用 | 主体衔接证据完整，并逐项判断本项目适用性 |

| HF-D09 | 证书、查询或审计存在有效时点要求 | 只判断“资料库有文件”，未核对日期窗口 | 主体、年度、有效期和招标要求的时点逐项成立 |
| HF-D10 | 条件式承诺表保留 | 原表正文存在但填写线、签章位或三种情形不完整 | 原格式完整，填写处理与实际适用性不制造矛盾声明 |

## E 技术响应、车型与历史复用

| 编号 | 适用条件 | 检查内容与典型问题 | 通过标准 |
|---|---|---|---|
| HF-E01 | 一个项目含一个或多个车型 | 不同车型条款、报告、证书或参数交叉 | 每个车型独立分组，车型清单、报告和响应一一对应 |
| HF-E02 | 同型号存在多个报告或近似配置 | 仅按文件名/相似度选错功率、电压、尺寸或配置 | 候选按业务参数方向重排，并记录选用及排除理由 |
| HF-E03 | 采用历史成熟响应 | 只复制标题，正文、表格仍含旧项目地点、车型、数量、期限或服务对象 | 复用台账列出替换字段；标题、正文、表格和进度节点全部完成本项目替换 |
| HF-E04 | 技术要求包含参数后的证件、运输、服务、检验、质保或付款条款 | 提取在参数末尾提前停止，或只机械改称谓 | 原顺序覆盖至末项，每条写明实际提供内容、期限和责任 |
| HF-E05 | 独立横向技术对标XLSX逐条作答 | 原文漏项、重编序号、回答简化条件或加入招标未要求配置 | 原文逐字锁定；答复尽量完整复述并转应答语气；正式DOCX详细表填写区留空 |
| HF-E06 | 评分要求形成技术章节 | 关键评分文字未成为次级标题，正文仅为模型自拟概述 | 以评分项/评价对象为标题，优先复用权威库成熟完整章节后作项目化调整 |
| HF-E07 | 技术支持或服务章节来自历史文件 | 成熟章节被压缩成几段泛化文字 | 子标题、措施、表格和企业能力内容整体保留，按本项目差异最小修改 |
| HF-E11 | 使用模块化权威库 | 正文无法反查模块ID，或把`reference_only/needs_review/excluded`内容作为成熟章节 | 每个复用章节有模块ID和台账；正式正文只采用合格模块或明确的项目新写内容 |
| HF-E12 | 同一目录节点采用多个模块 | 标题、措施或表格重复，模块衔接断裂 | 明确主模块与补充模块，去重后逻辑连续且来源关系保留 |
| HF-E08 | 响应表引用证明材料 | 正文写“详见”但附件未实际附入，或一份整车报告代替全部部件证明 | 引用文件真实存在、适用并进入成品；材料类型分别核对 |
| HF-E09 | 用户或招标规定响应表不显示来源页数 | 自增“来源页数、招标印刷页码”等阅读干扰列 | 删除非强制来源页数字段；强制定位栏、目录页码和材料索引保留 |
| HF-E10 | 地面/井下设备或车辆/充电设备同时出现 | 设备类别混淆、把参考型号或车辆型号当实际充电设备型号 | 按设备类别分别选型，实际型号有依据；未确认时不虚构 |

| HF-G12 | 附入身份证正反面 | 身份证按版心放大、跨页、比例失真或裁切 | 招标未规定时按宽8.56厘米等比显示，同一人的正反面在同一独立页面居中排列 |
| HF-G13 | 文件含图片材料或多个附件 | 下一章节接在图片下方、两个附件同页混排，或附件标题孤立在上一页 | 每个附件从新页开始；标题与首张材料同页，多页附件连续；图片材料结束后下一章节、表单或附件另起一页 |
| HF-G14 | 文件含多个正式目录章、节或子节 | 新节接在上一节内容后，或分页后形成只有标题的孤立页 | 招标未规定连续排版时，每个正式目录节点从新页开始；标题与本节首段、首表或首张材料同页，长节自然跨页 |
| HF-G15 | 本次业绩及正式商务、技术偏差表 | 三类表被自动填写、原固定结构变化或业绩证明被附入 | 与招标原表逐格比较：固定内容完整、填写区空白；无业绩证明；内部技术结论独立保留 |

## H 最终逐页与跨卷一致性

| 编号 | 适用条件 | 检查内容与典型问题 | 通过标准 |
|---|---|---|---|
| HF-H01 | 所有本次交付DOCX | 只看拼图、自动扫描或典型页，未逐页打开 | 每页在可读尺度有实际观察记录 |
| HF-H02 | 局部修订旧成果 | 只检查修改页，不判断分页对后文和目录的影响 | 变化页、前后衔接页、全部受影响页码和引用均复查 |
| HF-H03 | 同一事实跨多个位置出现 | 型号、参数、数量、期限、地点、偏离结论前后冲突 | 报价/交货表、响应、方案、偏差表、附件和目录使用同一事实记录 |
| HF-H04 | 正文含材料引用 | 引用名称、原件页或附件位置无法反查 | 每个正式引用均对应实际附入且适用的原件 |
| HF-H05 | 最终文件含目录 | 目录域/目录段落仅在脚本中存在，成品没有目次页 | 最终DOCX和页图均能看到目录，页码单调且准确 |
| HF-H06 | 最终页图完成 | 遮挡、截断、异常空白、孤立标题、错误方向或页眉页脚串节 | 全部异常已修订或有明确不影响递交的依据 |
| HF-H07 | 使用历史反馈清单 | 只在卷级写“已检查”，未按编号反查 | 每个适用编号均有位置和结论；重复反馈项不得再次出现 |
| HF-H08 | 声称完成逐页视觉检查 | 只生成全页图片或查看联系表，未逐页打开并留下页面结论 | 页级记录数与最终页数相等，每页含适用问题项和实际观察；联系表及自动信号不能代替 |

## 项目适用清单生成

制作开始时从本清单筛选项目适用项，不复制全部条目作为形式化报告。下列条件至少触发对应组：

- 有招标模板：A组；有封面/目录/分部：C组；有商务资格材料：D组；有技术内容：E、F组。
- 生成或修订DOCX：G、H组始终适用。
- 使用历史文件或权威库：HF-B07、HF-E03、HF-E06、HF-E07必须适用。
- 存在保证金转账、条件式信誉承诺、交付适配、完整合卷或旧卷替换时，分别启用对应专项条目。

发现新的业务反馈时，先判断能否归入现有编号；只有检查对象、失败模式或通过标准实质不同才新增编号，避免同一问题重复堆叠。
