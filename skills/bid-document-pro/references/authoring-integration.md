# 总控七阶段与执行十步

| 总控阶段 | 既有十步位置 | 不可替换的能力 |
|---|---|---|
| 建档、精读 | 1 | 输入冻结、原文覆盖、骨架、槽位和渲染锁 |
| 资格与红线 | 1、3、5 | 原资格证据、条件式声明和缺项状态 |
| 评分拆解 | 1、4、6、7 | 原评分驱动目录、完整模块和报告级技术选材 |
| 商务/技术/价格编制 | 2—8 | 实填正文、技术内部Excel、正式表留空及附件证明 |
| 排版封装 | 9 | 原DOCX生产、Office渲染、目录页码和包内验证 |
| 三级自查 | 8、10 | bid-parse-qc四重报告、原历史问题清单和逐页终审 |

主制作技能已启用时不另建项目、不绕过门禁、不换成通用三册模板、通用字体或强制Word MCP。操作手册仍受保护，用户要求加本技能不授权修改手册。已有项目不自动获得新检查通过状态。

内部解读、风险、评分和递交清单可使用现有同义数据，保留稳定要求ID和当前成品定位。阶段检查完不是所有条件已满足；源码/输入/资料变化按主流程使相关步骤失效。报价未批准、签署缺失、资料缺项、视觉未检查仍明确记录。

独立调用本技能且要求原SOP的Word MCP时，工具不可用必须报告，另用现有DOCX生产须明确许可；不能假称MCP存在。单纯读标和评分策划可继续，不因Word工具不足阻塞无关工作。
