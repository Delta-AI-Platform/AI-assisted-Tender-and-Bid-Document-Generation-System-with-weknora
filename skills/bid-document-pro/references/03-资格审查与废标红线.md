# 资格与否决核查

动态从公告、须知、评审及引用正文收集本标段条件。资质、人员、财务、资格业绩、信誉、制造商/代理商、联合体等有才列，原文未涉及不编成“无要求”。

每项核主体、等级/范围、适用年度、有效日期、提交时点、证明方式及例外；资格、评分加分和交付阶段义务不得混用。旧证与续期事实、新原件是否实际取得分开。已选证明须进入实际成品或要求的独立附件。

| 状态 | 判断 |
|---|---|
| 已满足 | 当前证据与原文条件对应，并有实际成品位置 |
| 待核/待补 | 未取得、未读清、范围冲突或未嵌入，不能反推企业不具备 |
| 不满足 | 有证据确认不符合；是否否决须原文与适用规则支持 |

超限、保证金、签章、份数、密封、暗标、电子操作和强制参数等仅是查找线索，不是全国一律废标清单。合法处理为补证、核实适用性、澄清或有依据的替代，不隐瞒差异、伪造或绕过门槛。
