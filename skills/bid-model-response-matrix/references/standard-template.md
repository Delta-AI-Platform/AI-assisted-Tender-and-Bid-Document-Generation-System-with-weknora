# 标准模板（定稿版式）

本文件是「车型标准响应参考表」的**出厂模板**。2026-10-21 业务定稿版（v15，390 数据行）即按此产出；
新建表、返工重排、验收比对都以本文件为准，不要再另立版式。

## 1. 画布参数

| 项 | 取值 |
|---|---|
| 工作表 | 单 sheet，命名「车型标准响应对照」 |
| 列 | 固定 8 列 A–H（见第 2 节），不加序号列、不加备注列 |
| 列宽 | A 22 / B 20 / C 22 / D 24 / E 46 / F 46 / G 46 / H 12 |
| 行高 | 表头 32，说明行 42，数据行默认 |
| 字体 | 表头 微软雅黑 10 加粗；正文 微软雅黑 9；说明行 微软雅黑 9 斜体 |
| 表头底色 | D9E2F3（浅蓝），居中 |
| 模块列底色 | FCE4D6（浅橙），仅模块名首行填充；其余列**一律无底色** |
| 边框 | 全部数据单元格细边框 |
| 冻结窗格 | **E3**（冻结表头 + 说明行 + 前四列）。必须在插行、合并全部完成后设置，否则 freeze 不随 `insert_rows` 平移，会冻到表尾 |
| 自动筛选 | **不加**。说明行是 A2:H2 合并单元格，落在筛选范围内会被当数据行过滤掉 |
| 合并 | 车型 / 子系统 / 部件三列同值连续行纵向合并；说明行 A2:H2 横向合并 |

## 2. 列定义

| 列 | 表头 | 内容 |
|---|---|---|
| A | 车型 | 投标车型（原文字样，如「矿用防爆指挥车 WLR-5」）；通用章节填「通用要求」 |
| B | 子系统模块 | 子系统/章级分类（总则、供货范围、引用标准、运行环境、备品备件、动力系统…） |
| C | 部件模块 | 部件级分类；明细类填组标题「一、行走/转向系统」 |
| D | 功能模块 | 本条功能名（参数名 / 条款题名 / 物料名称 / 组标题） |
| E | 标准车型答案（历史投标响应） | 同车型历史响应原文；无同车型历史**留空**（详见 §2.1） |
| F | 本次招标要求 | **招标原文**，行首带原文编号 |
| G | 投标人响应 | **答复句式**，行首编号与 F 列一致 |
| H | 偏离说明 | 只写「无偏离/正偏离/负偏离」；无偏离不写补充说明 |

## 2.1 E 列（标准车型答案）的填报门禁（2026-10-22 陈家沟项目业务口径）

E 列是**证据列**，不是占位列。只填「与本次招标要求确属同一事项、可直接对照」的历史响应原文，其余**留空**。

| 情形 | 处理 |
|---|---|
| 同车型、同一事项，历史响应可直接对照 | 填历史响应原文（保留其编号） |
| 无同车型历史 | **留空**。不写「无同车型历史」「无历史响应」「—」「暂无」 |
| 有历史，但条款事项与响应不同层（如要求「制动距离≤8m」配上「制动系统构成」） | **留空**。参数条尤其不能拿系统构成响应充数 |
| 历史值与本条要求数值不同（要求 ≥100kW，历史 70kW） | **留空**。数值不可跨车型挪用，写上去就是虚假响应 |
| 条款主体是品牌等同性 / 参照或相当于 / 资料补发 / 图纸复制 等程序性要求 | **留空**。功能类响应套上去属于答非所问 |

实操判据：**「把这条历史响应盖住编号后，还能当成本条的答复读通吗？」** 读不通就留空。

放宽口径的代价是双向的：填错会被评标专家当作「以他车型参数冒充本车型」，比留空严重得多。
说明行（R1）相应写成「仅填写与本次要求确属同一事项的历史响应，其余留空，不以近似条款或他车型参数充填」，
不要写「标注无同车型历史」——表里根本没有这类文字，说明与实物对不上。

## 3. 六类行型（照此填写）

### R1 说明行（第 2 行，A2:H2 合并，斜体）

> 说明：“标准车型答案”列取自以往投标项目同车型（WLR-5C(E)）的实际响应原文。WC5JA 升降车、GZC2/500 抓举车及防爆柴油机尾气净化装置无同车型历史投标案例，相应条目仅有现行参数，不构成历史响应依据。正偏离条目的“投标人响应”与“偏离说明”两列以红色字体加粗标注；负偏离以蓝色字体加粗标注。

### R2 章节标题行：**要求 = 响应 = 照抄原文**

| F | G | H |
|---|---|---|
| （四）设备运行环境条件 | （四）设备运行环境条件 | 无偏离 |
| 5.1.1 矿用防爆指挥车主要技术参数 | 5.1.1 矿用防爆指挥车主要技术参数 | 无偏离 |
| 一、行走/转向系统 | 一、行走/转向系统 | 无偏离 |

不写“我方完全响应本节全部要求”一类套话。标题行自身有实质内容的（如（三）引用标准整节只有一条），按 R3 逐条应答，不算标题行。

### R3 参数/条款行：编号在行首，要求照抄，响应给值

| F | G | H |
|---|---|---|
| 1．海拔高度：不超过1500m； | 1．投标车辆适用海拔高度不超过 1500m 的运行环境。车辆动力系统按海拔不超过 1500m 设计校核，功率裕度满足高原降效要求。 | 无偏离 |
| 本技术规格书提出的是最低限度的技术要求…供方应保证提供… | 所提供的产品为符合本技术规格书和有关最新工业标准的成熟的优质产品。本技术规格书提出的是最低限度的技术要求… | 无偏离 |

- 编号层级 = 章节号 + 原文号（`5.1.1.15`、`6.2.5.1`、`7.1.1`）；原文无子序号时用条款号（`6.2.6、`）
- 子级行不重复上级前缀：`1．…` 不写 `（二）1．…`

### R4 明细组标题行（备品备件/供货清单）

| D | F | G | H |
|---|---|---|---|
| 一、行走/转向系统 | 一、行走/转向系统 | 一、行走/转向系统 | 无偏离 |

组标题必须单独成行，**不要把组号拼进条目行**。

### R5 明细条目行：组内序号 `1．2．3．` 排开，不带组号

| F | G | H |
|---|---|---|
| 1．三电系统防爆密封；单位：套；数量：1；原车原厂正品、随货提供 | 1．提供三电系统防爆密封，单位：套，数量：1，原车原厂正品、随货提供。 | 无偏离 |
| 4．各油管高压防爆胶管总成（含管接头）；单位：套；数量：各2根；原车原厂正品、随货提供 | 4．提供各油管高压防爆胶管总成（含管接头），单位：套，数量：各2根，原车原厂正品、随货提供。 | 无偏离 |
| 7．组合工具（套筒）；单位：套；数量：1；设备检修用 | 7．提供组合工具（套筒），单位：套，数量：1，用于设备检修。 | 无偏离 |

- 数量照抄原文（「各2根」不改写）；备注「设备检修用」的响应写「……用于设备检修。」

### R6 注释/说明行

| F | G | H |
|---|---|---|
| 注：上述各车型备品备件明细表，均为【单台车辆配套1套备品备件】物料清单。投标人报价时，须按… | 投标报价已按【单台备件数量×对应车型采购台数】核算各车型备品备件总数量；全部备品备件为标配随货供货，相关费用统一包含在投标总价及项目最高投标限价内。 | 无偏离 |

注释也成行，不能只放在标题行里带过。

## 4. 响应写法四原则

1. **答复句式**：招标的“供方应／应予以配合／不得…”直接改写为“所供…为／均予配合／不会…”，不保留“我方承诺／我方保证／完全响应”固定前缀。
2. **逐条镜像**：一条要求对一条响应，要素（名称、单位、数量、指标、条件）逐项重述，不简写、不合并、不用概况话术。
3. **不越话题域**：说明与响应只谈本条要求的话题。续航条不写电机、不写电池衰减；单功能条不搭售相邻功能。
4. **不虚构**：参数、证书编号、报告名、承诺只写有出处的内容；历史响应没有的（如某车型安标编号）只写“取得安标证书及 MA 标识”。

## 5. 偏离与配色

| 偏离 | 说明列 | 色标（只改字体，不加底色） |
|---|---|---|
| 无偏离 | 只写「无偏离」，不带补充说明 | 默认黑字 |
| 正偏离 | 「正偏离」+ 说明（必须是本条要求的数值/能力优势） | G、H 两列红字 C00000 加粗 |
| 负偏离 | 「负偏离」+ 说明（原因、影响、补救） | G、H 两列蓝字 0070C0 加粗 |

判等原则：数值相等（25 对 25）、指标相同、功能同名即**无偏离**，不得写成正偏离。

## 6. 编号速查

| 原文形态 | 输出编号 |
|---|---|
| 表格行 `1.` 型（挂节号） | `7.1`；其后括号项 `（1）` → `7.1.1` |
| 短标题括号（≤12 字、不以句号结尾） | 作父级，其下 `1、2、3` → `9.2.1` |
| 无结构括号项 | 直接挂节号 → `6.2.5.1` |
| 原文整条无子序号 | 用条款号 `6.2.6、` |
| 备件组内序号 | 组标题行 + `1．2．3．`（不拼组号） |

## 7. 交付前自检（8 项）

- [ ] 行序 = 招标原文节序（不按车型/模块归并）
- [ ] 全文覆盖：总则、供货范围、引用标准、运行环境、备品备件、各章标题行无遗漏
- [ ] 标题行 F = G = 原文；无“完全响应本节全部要求”套话
- [ ] 子级行无 `（X）数字` 上级前缀
- [ ] 明细：组标题行数 = 原文组数，条目行数 = 原文条目数，逐条与原文一致
- [ ] 无偏离说明残留 0；正偏离必要优势且说明限本条话题域
- [ ] 正偏离红字、负偏离蓝字，**均无底色**
- [ ] 冻结 E3、无自动筛选、说明行 A2:H2 合并
