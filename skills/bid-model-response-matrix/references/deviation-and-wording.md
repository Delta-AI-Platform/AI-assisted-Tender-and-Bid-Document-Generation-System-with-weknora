# 偏离判定与响应措辞

## 三层结构

```
应答正文（应答值 + 关键条件）
<空行>
优于补充说明：……（只在正偏离时出现）
<空行>
证明材料详见：……（只在正偏离时出现）
```

| 偏离 | 响应列内容 |
|---|---|
| 无偏离 | **只写应答正文**。不写补充说明、不写证明材料 |
| 正偏离 | 应答正文 + 优于补充说明 + 证明材料详见 |
| 负偏离 | 应答正文 + 补充说明（写清实际值与差距） |

「无偏离不写说明」是硬口径：说明只用于解释偏离。历史上曾出现 3 条无偏离带说明，被业务逐条指出。

## 偏离怎么判

**无偏离**：投标值满足要求；或与要求同值；或差异不构成不利（如宽度略窄但载人空间不变，仍需在正偏离里说清，不能默认）。

**正偏离**：同时满足三条——

1. 有可比数值或可验证能力，且方向确实更优（`≥` 要更大、`≤` 要更小）；
2. 说明主体 = 本条要求的对象；
3. 有证明材料能兜住（安标证、检验报告、第三方测试）。

**负偏离**：不满足要求。写实际值、差距、补救或承诺，不粉饰。对外口径若要求统一填"无偏离"，也必须在本列或备注留差异说明，不能凭空说满足。

## 十条铁律（每条都对应一次真实退回）

| # | 铁律 | 真实反例 | 正确做法 |
|---|---|---|---|
| 1 | 数值相同不得判正偏离 | 最高车速要求 ≥25，投标 25，判了正偏离 | 无偏离，只写 25 |
| 2 | 无偏离不写说明 | 续航、车速、售后三条无偏离带"补充说明" | 剥掉说明层 |
| 3 | 说明主体必须是本条对象 | 续航里程条写"与永磁电机、电控匹配" | 只谈续航保障与工况 |
| 4 | 说明范围限于本条话题域 | 续航条写电池自放电 90 天、三年衰减 | 电池话题留给电池条 |
| 5 | 不得笼统说"均优于" | 外形尺寸称"长宽高均优于"，实际只有宽度窄 100mm | 逐项对比：长高一致、宽 1850＜1950 |
| 6 | 不得引用错对象 | 电机控制器功率条写"电机 TBVF-70/8YC" | 写控制器 KBT-70，70kW＞60 |
| 7 | 禁止"已满足" | 响应里 116 处"已满足" | 直接陈述满足状态或删句末标记 |
| 8 | 不得虚构参数/证书/报告 | 为凑正偏离编报告名 | 无证据就降为无偏离或标待确认 |
| 9 | 历史值与本次证明材料冲突时以证明材料为准 | 历史 70.656kWh 对要求 ≥72（实为负偏离），本次证书 73.6kWh | 按证书据实应答，并提示技术部确认串数口径 |
| 10 | 一条一答，不合并、不漏项 | 把 5 个条目的通用话术复制到 5 行 | 每行独立成句，按本条重写 |

## 措辞规范

- **要求词 → 答复词**：「应具备」→「具备」；「须满足」→「满足」；「推荐选用」→「选用」。
- **保留原文全部限定条件**：工况、温度、坡度、载荷、时长一个都不能少；少一个条件就是把承诺放大。
- **不承诺招标未要求的内容**：不额外送服务、不额外加配置，除非业务明确要写。
- **篇幅精简**：一条 1–3 句；优于说明不超过 3 句 + 一条证明材料。
- **数值带单位与口径**：`73.6kWh（额定 320V／230Ah，1P100S）`，不要只写 73.6。
- **不用小标题、不用星号、不用 markdown**：单元格是给 Word/打印看的。
- **中文标点**：全角，句末不加多余空格。

## 修订层：每次改写都留"为什么"

业务反馈往往是一句话（"这条不对"）。把修订写成可审计的结构，而不是直接改字符串：

```json
"5.1.1#14": {
  "why": "招标要求仅涉及续航里程，说明中不得引入电池自放电、三年衰减等电池话题",
  "dev": "无偏离",
  "resp": "续航里程（km）：≥120（矿井综合运行工况）"
}
```

键 = `条款号#行索引`（表格行按 0 起，段落按 clause 下标）。好处：

- 复审能回答"为什么这么改"；
- 重建表格时不会被覆盖丢失；
- 同一批反馈可以一次性回归验证。

## 交付前必看的三类条目

1. **数值类**（能量、续航、功率、尺寸、载重、爬坡）：逐条对证书/报告，确认投标值不是抄历史值。
2. **跨条目复用语**：出现两次以上的相同说明，逐条确认主体是否换了。
3. **无历史条目**：响应来自产品资料或业务拟制，标"待技术部确认"，不要伪装成历史答案。

## 过度承诺红线（业务红字划除的五类，2026-10-21 审查实例）

正偏离说明里最容易写出的五类过度承诺，全部被业务红字划掉：

| # | 红线 | 被划掉的实例 | 为什么过度 |
|---|---|---|---|
| 1 | 自证式对应 | 响应里照抄推荐品牌清单“常州科试、湖南宇牵、中车电机或相当于同等质量及以上产品” | 自研品牌不在推荐清单内，照抄清单反而构成虚假对应；只写实际品牌 |
| 2 | 要求内数值括注重复 | “73.6（额定 320V／230Ah，1P100S），≥72” | 73.6 已高于 ≥72，括注是重复承诺，删掉只留实际值 |
| 3 | 要求外功能搭售 | 驾驶员检测、环视说明里带“接近安全防护、” | 招标该条只要求单一功能，说明超出话题域即属承诺放大 |
| 4 | 具体指标整段超承诺 | 数据上传条写“配置井下定位；无条件上传；传送频率 60s 以内可调；CAN2.0B” | 招标只要求“具备数据上传功能”，全部具体指标都没有证明材料兜底 |
| 5 | 改装/一致性自证 | “为招标参考型号的同平台改进型，整车布置、载人数量及主要技术参数与 WLR-5 一致” | 同平台一致是可被逐项质证的主张，无报告支撑不写 |

判据一句话：**说明里每一个可质证的具体主张，都必须有招标要求出处或证明材料出处；两者都没有就删。**

## 偏离的颜色标记（2026-10-21 业务四轮定稿）

偏离两列同色、一眼可扫——色标范围是"投标人响应"+"偏离说明"**两列**，不只偏离说明列。
**只改字体颜色，一律不加单元格背景色**（底色会盖掉模块列的浅灰分组，整表观感变花，业务明确要求去掉）：

- **正偏离**：两列**红字（C00000）+ 加粗**，无底色；
- **负偏离**：两列**蓝字（0070C0）+ 加粗**，无底色；
- 无偏离：默认黑字无底色；
- 构建器统一上色，不允许业务在标记稿上手补颜色。

openpyxl 实现要点：把单元格 fill 显式设为 `PatternFill(fill_type=None)`，不要只"不加 fill"——
若该行先被其他样式（如模块列填充、表头样式）赋过底色，残留底色会跟着走到偏离行。

沿革：第一版只有偏离说明列蓝底蓝字（"正偏离没有突出颜色差异标记"退回后加）；第三版改为正红/负蓝并覆盖响应列；
第四版按"只标红字体 不要标红背景"去掉全部底色——口径以本节为准。

## 业务标记回收（标记版 xlsx → 修订层）

业务退回的标记版用 `scripts/parse_marked_review.py` 解析：

1. **黄色填充 = 缺失**：常见两类——业务手工插入的章节标题行/空行（提示标题也要成行响应），整段漏转化的章节（如总则~环境条件、备品备件明细）。处理：回招标原文找到原始文本逐条转化，低一级序号保留原样。
2. **红字/划掉 = 过度承诺**：取“保留片段拼接稿”为该条 resp 新值（脚本已剥行首编号、清理标点），写修订层并记 why。
3. **蓝字改写 = 业务终稿**：业务手写内容原样采纳，不再润色。
4. 回收后必须做**底稿版本比对**：标记版的底稿可能比最新交付旧，逐格 diff 确认哪些差异是底稿旧、哪些是业务改动，旧差异以最新口径为准并在汇报中说明。

## 章节标题行的响应写法（2026-10-21 业务二轮审查）

章节标题行（（一）总则、（四）设备运行环境条件、（五）技术参数、5.1/5.1.1、备件表标题等）成行后，
响应列**直接复制本次招标要求原文**，不写“我方完全响应本节全部要求”一类套话——
业务口径：“类似标题 响应处完全复制本次招标要求即可”。

注意：有实质内容的节（如（三）引用标准整节只有一条）不是纯标题行，响应仍按逐条应答写，
行首保留本节编号（（三）我方设计…），不受本条约束。

## 通用要求的答复表述（2026-10-21 业务四轮定稿）

总则、供货范围、引用标准、运行环境、备品备件等通用要求的响应不能简写成一句话缩写，
要参照历史投标响应的写法，把招标的**要求句式直接改写为答复句式**——
**不用"我方承诺：""我方保证：""完全响应"这类固定前缀**，而是换主语、换语气：

| 招标要求句式 | 答复句式（改写后） |
|---|---|
| 供方应保证提供符合…的成熟的优质产品 | 所提供的产品为符合…的成熟的优质产品 |
| 如供方没有书面提出异议，则意味着设备完全符合要求 | 所提供的设备完全符合本技术规格书的要求；凡未书面提出异议的条文，均视为完全符合 |
| 供方应予以配合 | 均予以配合 |
| 投标方所提供的车辆须满足矿用要求 | 所提供的车辆满足矿用要求（历史响应原句风格） |
| 供货 X 台 | 提供 X 台（"供货"改写为"提供"） |
| 标准清单 | 逐项列"标准——符合"，收尾写高标准优先原则 |

**不简写**：每条要保留要求里的全部条件与指标，并补上实现措施（措施来源限历史响应或产品资料）。
红线不变：历史没有的证书号、参数不虚构（如安标编号只有指挥车 MCG240737 有历史依据）。

## 明细类条目的排版与响应（2026-10-21 业务五轮审查定稿）

备品备件明细、供货清单一类逐条物料表，按招标原文层级排版（同 9.5/9.5.1 的拆分逻辑）：

1. **组标题单独成行**：要求=响应=照抄原文组标题（“一、行走/转向系统”“二、制动系统”）；
   不要把组号拼进条目行（“二、制动系统 序号1：…”被否——“按照标题一列 底下 12345678排开”）。
2. **条目行**：组内序号 1．2．3．排开，不带组号——
   要求：“1．三电系统防爆密封；单位：套；数量：1；原车原厂正品、随货提供”
   响应：“1．提供三电系统防爆密封，单位：套，数量：1，原车原厂正品、随货提供。”
3. 特殊数量照抄（“数量：各2根”）；备注“设备检修用”的响应写“……用于设备检修。”
4. **响应逐条镜像**，禁止多条明细共用一句概况话术——
   业务原话：“响应要和要求一样 不准这样偷懒 概况填写”。
5. 原文的“规格型号”“单价”列在招标文件中为空白，响应表不体现。
